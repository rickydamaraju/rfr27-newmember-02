# Code Plan

This code runs on a typical 5V Arduino Nano (ATmega328P). This code takes measurements from sensors, finds which one has the highest valid measurement, controls a red LED based upon those measurements, and sends the results via I2C. Prior to scanning channels, the code configures the multiplexer control lines, ADC, LED, and I2C address 0x32. Then it scans Channels 0 through 7. For each channel, the code changes the multiplexer, allows time for the signal to stabilize, ignores one ADC measurement, and averages eight more measurements. Next, the code converts the average ADC measurement to volts using the ADC Reference Value.

Finally, the code uses that sensor's Calibration Values to determine Temperature. If a measurement is beyond its expected range, it is considered "invalid" and cannot be used to identify the warmest sensor. The Red LED will flash if either the highest valid temperature is greater than 60 degrees C or if any sensor appears to be defective. Once a High-Temperature Alert occurs, the temperature must drop to 58 degrees C or lower with all sensors valid before the alert can clear. The most recent results are written to two I2C Pages. Page 0 contains the Maximum Temperature. Page 1 contains the Individual Readings for all 8 Sensors. An External Controller chooses a Page and Reads 22 Bytes. Each Scan begins approximately every 50 Milliseconds. This timing still needs to be verified on the actual hardware. The single firmware.ino file handles the Nano hardware, temperature calculations, I2C data, and example calibration values. Those values are examples because we do not yet know the type of diode provided.
