# Code Plan

This code runs on a typical 5V Arduino Nano (ATmega328P). This code takes measurements from sensors, finds which one has the highest valid measurement, controls a red LED based upon those measurements, and sends the results via I2C. Prior to scanning channels, the code configures the multiplexers' control lines, ADC, LED, Timer, and I2C address 0x32. Then it scans Channels 0 through 15. For each channel, the code changes the multiplexer, allows time for the signal to stabilize, ignores one ADC measurement, and averages eight more measurements. Next, the code converts the average ADC measurement to volts using the ADC Reference Value.

Finally, the code uses that sensor's Calibration Values to determine Temperature. If a measurement is beyond its expected range, it is considered "invalid" and cannot be used to identify the warmest sensor. The Red LED will flash if either the highest valid temperature is greater than 60 degrees C or if any sensor appears to be defective. Once a High-Temperature Alert occurs, the temperature must drop below 58 degrees C with all sensors valid before the alert can clear. The most recent results are written to three I2C Pages. Page 0 contains the Maximum Temperature. Pages 1 & 2 contain the Individual Readings for all 16 Sensors. An External Controller chooses a Page and Reads 22 Bytes. Each Scan begins approximately every 50 Milliseconds; however, this timing still needs to be verified on the actual hardware. Currently, Main.C manages the Nano Hardware, Monitor.C computes Temperatures and Formats the I2C Data, and Calibration.H stores Calibration Values. These Values are just Examples since we don't know what kind of Diode was included.
